## Estrutura

## Rodar localmente

Abra o `index.html` no navegador ou sirva a pasta com qualquer servidor estático, por exemplo:

```bash
npx serve .
```

Pode ser publicado direto no GitHub Pages (Settings → Pages → branch `main`, pasta `/`).
